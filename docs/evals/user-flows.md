# User Flows

## First Launch

1. User opens SpeakCareer.
2. User sees the positioning and English MVP focus.
3. User taps Start practicing.
4. User lands on Home with a recommended roleplay.

## Start a Roleplay

1. User opens Home or Practice.
2. User selects a roleplay scenario.
3. User reads the context, goal and AI opening line.
4. User reviews useful phrases.
5. User sees mock AI feedback.

## Review Progress

1. User opens Progress.
2. User reviews sessions, minutes and skill scores.
3. User checks the mistake bank.
4. User chooses the next focus area.

## Understand Profile State

1. User opens Profile.
2. User sees English as the active MVP language.
3. User sees Spanish, French and Mandarin Chinese as planned later.
4. User sees integrations marked as later, not connected.
