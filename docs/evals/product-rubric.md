# Product Rubric

Use this rubric after each build step.

Score each area from 1 to 5.

## 1. Career Usefulness

The feature helps users practice real professional English conversations.

## 2. MVP Focus

The feature supports the English MVP and avoids premature integrations.

## 3. Professional Tone

The UI and content feel useful for adults at work, not childish or game-like.

## 4. Simplicity

The implementation is easy to understand and extend.

## 5. Feedback Quality

The user can understand what went well, what to improve and what to say instead.

## 6. Safety and Privacy

No real secrets, private user data or unnecessary external services are added.

## Pass Bar

A change is acceptable when every category scores at least 4, or when any lower score is documented with the next fix.
