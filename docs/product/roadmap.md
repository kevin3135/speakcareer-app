# Roadmap

## Phase 1: English Mock MVP

- Local Expo React Native app.
- Onboarding, Home, Practice, Roleplay, Progress and Profile screens.
- Five core professional roleplays.
- Mock AI feedback UI.
- Local progress and mistake bank data.

## Phase 2: Local Practice Loop

- Typed practice input.
- Local session history.
- Rule-based mock feedback based on the typed answer.
- More prompt variants per scenario.
- Better progress states.

## Phase 3: Backend and AI

- Add Supabase auth and database.
- Add a backend endpoint for OpenAI calls.
- Store roleplay sessions and feedback.
- Add basic rate limits and safety checks.

## Phase 4: Product Instrumentation

- Add Sentry for errors.
- Add PostHog for product analytics.
- Define activation, retention and conversion events.

## Phase 5: Monetization

- Add RevenueCat only after the practice loop shows value.
- Keep free practice useful enough for trust.
- Add subscription gates around advanced feedback, history or high usage.

## Phase 6: More Languages

- Add Spanish, French and Mandarin Chinese after English content, feedback and retention are strong.
